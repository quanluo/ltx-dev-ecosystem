# Contributing

Thanks for helping improve independent AI video ecosystem discovery.

## Suggesting a resource

Open an issue with:

- resource name and canonical URL;
- owner or maintainer;
- supported model/tool versions;
- what task it helps users complete;
- reproduction or evaluation instructions;
- license for code and media;
- your relationship to the resource.

## Acceptance criteria

Resources must be directly relevant, maintained or clearly archived, accurately
labeled, and safe to link. We reject keyword-stuffed descriptions, affiliate
redirects without disclosure, copied documentation, reciprocal-link demands,
and unverifiable performance claims.

## Pull requests

Keep descriptions factual and concise. Use descriptive link text. Update the
review date when you verify an existing entry. A listing is an editorial
reference, not an endorsement.
