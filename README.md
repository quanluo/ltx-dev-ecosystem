## Ecosystem loop

```text
                 LTX.dev
        text / image / audio / video
                    ↕
          Model comparison guides
                    ↕
   Workflows ↔ Examples ↔ Prompt cookbook
                    ↕
       Canonical upstream repositories
```

Every repository links back to the relevant LTX.dev task and to at least one
adjacent ecosystem resource. The goal is useful navigation, not reciprocal-link
padding.

## Resource directory

The [reviewed resource directory](docs/resources.md) distinguishes:

- LTX.dev platform resources;
- official model-provider resources;
- independent documentation and examples;
- community-owned tools.

## Editorial principles

1. **Independent identity.** Never imply that LTX.dev owns or officially
   represents a third-party model.
2. **Useful before promotional.** A resource must solve a real user task.
3. **Primary sources first.** Version, pricing, license, and capability claims
   link to the platform or model owner.
4. **Dated comparisons.** Dynamic specifications include a review date.
5. **No link schemes.** Links follow the user journey and are never exchanged
   for payment or unrelated mentions.
