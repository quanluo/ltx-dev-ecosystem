# LTX Video Ecosystem Map

Last reviewed: 2026-07-30

## Canonical upstream

- [Lightricks/LTX-2](https://github.com/Lightricks/LTX-2) — current official
  Python inference pipelines and LoRA trainer for LTX-2.
- [Lightricks/ComfyUI-LTXVideo](https://github.com/Lightricks/ComfyUI-LTXVideo)
  — official ComfyUI integration.
- [Official LTX documentation](https://docs.ltx.io) — canonical product and API
  documentation.
- [LTX-2 models on Hugging Face](https://huggingface.co/Lightricks/LTX-2.3) —
  official model distribution.

## Independent LTX.dev resources

LTX.dev is a separate multi-model platform. The repositories below provide
independent learning and discovery resources and do not replace upstream
documentation:

- [Examples](https://github.com/quanluo/ltx-video-examples)
- [ComfyUI workflow index](https://github.com/quanluo/ltx-comfyui-workflows)
- [Prompt cookbook](https://github.com/quanluo/ltx-video-prompts)
- [Practical documentation](https://github.com/quanluo/ltx-video-docs)

## Community discovery

- [wildminder/awesome-ltx2](https://github.com/wildminder/awesome-ltx2) —
  community-maintained models, encoders, LoRAs, workflows, nodes, and guides.

Community entries are reviewed for relevance and transparency, not endorsed.
Open an issue to suggest an addition; do not submit paid or reciprocal links.
